# CodeMaster - Dusre Laptop Pe Kaise Chalayein

## Step 1: Python Install Karo
- Download: https://www.python.org/downloads/
- Version: Python 3.10 ya usse upar
- Install karte waqt "Add Python to PATH" checkbox zaroor tick karo ✅

## Step 2: Project Copy Karo
- ZIP file extract karo
- Kisi bhi folder mein rakh do (e.g., Desktop)

## Step 3: Setup Karo (Sirf Pehli Baar)
- setup.bat file pe double click karo
- Wait karo jab tak sab install ho jaye

## Step 4: Server Chalao
- run.bat file pe double click karo
- Browser mein jao: http://127.0.0.1:8000

## Step 5: AI Chatbot Ke Liye (Optional)
- .env file open karo (Notepad se)
- GEMINI_API_KEY=your-key-here likhdo
- Free API key: https://ai.google.dev/

## Login Credentials
- Admin: /admin/ pe jao
- Naya account banao: /users/register/

## Agar Koi Error Aaye
Command prompt mein ye commands chalao:
```
cd path\to\project
venv\Scripts\activate
python manage.py runserver
```
